# Урок 1: Типы данных

[English version](../01-data-types.md)

## Цель

Научиться выбирать базовые типы Go, объявлять переменные, понимать нулевые значения, явно преобразовывать значения и отличать байты от Unicode-кодовых точек.

После урока вы сможете прочитать и изменить программу в `lessons/01-data-types/main.go`, а также понять, что проверяют её тесты.

## Перед началом

В терминале из корня репозитория выполните:

```sh
go version
```

Команда должна вывести версию Go не ниже 1.22. Далее все команды в уроке запускаются из корня репозитория, то есть из каталога, где находится `go.mod`.

## Запуск примера

```sh
go run ./lessons/01-data-types
go test ./lessons/01-data-types
```

`go run` компилирует и запускает программу. `go test` запускает функции, имена которых начинаются с `Test`. Успешный тест означает, что фактический результат совпал с ожидаемым.

Ожидаемый вывод первой команды:

```text
name: "Go" (string)
visits: 0 (int), zero value
active: true (bool)
average: 2.3
bytes and runes in "Go язык": 11 and 7
20 C in Fahrenheit: 68.0
```

Не запоминайте эти строки как магию: ниже разберём, откуда берётся каждое значение.

## Базовые типы

| Тип | Для чего использовать |
| --- | --- |
| `bool` | `true` и `false` |
| `string` | неизменяемый текст в UTF-8 |
| `int` | обычные целочисленные вычисления и индексы |
| `int64` | размер целого числа задан API, размером файла или полем базы данных |
| `float64` | дробные значения и научные расчёты |
| `byte` | один байт бинарных данных или UTF-8 текста |
| `rune` | одна Unicode-кодовая точка |

Для обычных целых чисел предпочитайте `int`. Не выбирайте числовой тип только потому, что он «кажется безопаснее»; конкретная разрядность нужна, когда её требует API, протокол, база данных или ограничение памяти.

`uint` и другие беззнаковые типы не подходят автоматически для значений, которые «не бывают отрицательными», например возраста или количества. Вычитание из нуля у `uint` не даст ошибку, а переполнится в большое положительное число. Выбирайте их, только когда это требует внешний формат или побитовая операция.

```go
age := 27
var price float64 = 19.99
active := true
name := "Mira"
```

`:=` объявляет и инициализирует переменную внутри функции. `var` полезен, когда тип должен быть указан явно или значение появится позже.

В первой строке Go сам выводит тип `int` из значения `27`. Во второй строке тип указан явно: `19.99` становится `float64`. Имена переменных пишутся в `mixedCaps`: `userName`, а не `user_name`.

## Нулевые значения

У каждой объявленной переменной уже есть значение:

```go
var count int       // 0
var ratio float64   // 0
var enabled bool    // false
var title string    // ""
```

Это важно в Go: по возможности проектируйте типы так, чтобы их нулевое значение было полезным.

В работающем примере строка `var visits int` сразу создаёт переменную со значением `0`. Поэтому программа печатает `visits: 0`, хотя мы ничего не присваивали. Нулевое значение не означает «переменная не существует» и не равно `nil`: `nil` относится только к некоторым типам, которые изучим позже.

## Преобразования выполняются явно

Go не смешивает числовые типы неявно:

```go
completed := 7
total := 10
ratio := float64(completed) / float64(total)
```

Преобразование не является валидацией. Например, `int(3.9)` даст `3`; когда нужно округление, правило округления выбирают осознанно.

Следующая запись не скомпилируется, потому что операнды имеют разные типы:

```go
// ratio := completed / float64(total)
```

Ещё одна частая ошибка: целочисленное деление отбрасывает дробную часть. Выражение `7 / 3` имеет тип `int` и результат `2`. В функции `average` оба операнда сначала приводятся к `float64`, поэтому результат равен примерно `2.333...`.

## Разбор функций примера

```go
func average(total int, count int) float64 {
	if count == 0 {
		return 0
	}

	return float64(total) / float64(count)
}
```

- `func` начинает объявление функции.
- `average` - имя функции.
- `total int, count int` - два параметра типа `int`.
- `float64` после скобок - тип возвращаемого результата.
- `if count == 0` защищает от деления на ноль.
- `return 0` корректен: неявная константа `0` представима как `float64`.

Функция `celsiusToFahrenheit` принимает и возвращает `float64`, потому что температура может быть дробной. Внутри выражение `celsius*9/5 + 32` выполняется слева направо; так как `celsius` уже имеет тип `float64`, дробная часть не теряется.

## Строки, байты и руны

`len` возвращает число байтов, а не символов. Буквы UTF-8 могут занимать несколько байтов.

```go
word := "Go язык"
bytes := len(word)
characters := len([]rune(word))
```

Используйте `[]byte` для бинарных данных и закодированного текста. Используйте `rune` или `[]rune`, когда задача относится к Unicode-кодовым точкам. Ни один из этих вариантов автоматически не равен одному видимому человеку символу: графемные кластеры являются отдельной, более узкой темой.

В строке `"Go язык"` три ASCII-байта (`G`, `o` и пробел) и четыре кириллические буквы по два байта. Поэтому `len` возвращает $3 + 4 \cdot 2 = 11$. После преобразования в `[]rune` получаются семь кодовых точек: `G`, `o`, пробел, `я`, `з`, `ы`, `к`.

## Форматирование вывода

`fmt.Printf` печатает текст по шаблону. У него два вида аргументов:

```go
fmt.Printf("шаблон", значения_для_подстановки...)
```

Символ `%` начинает **форматный глагол**. Это не `$`: запись `$d` не имеет специального значения для `Printf`. Каждый глагол обычно использует следующее значение после строки шаблона, слева направо.

```go
fmt.Printf("name: %q (%T)\n", name, name)
```

Здесь первый `name` подставляется в `%q` и печатается как `"Go"`, а второй `name` подставляется в `%T` и печатается как `string`.

В программе используются:

| Шаблон | Значение |
| --- | --- |
| `%q` | строка с кавычками |
| `%T` | тип значения |
| `%d` | целое число |
| `%t` | булево значение |
| `%f` | число с плавающей точкой; по умолчанию шесть цифр после точки |
| `%.1f` | число с плавающей точкой и одной цифрой после точки |
| `%s` | строка без кавычек |
| `%v` | значение в стандартном представлении |
| `%%` | символ процента |

В `%.1f`:

- `%` начинает форматный глагол;
- `.` начинает настройку точности;
- `1` означает одну цифру после десятичной точки;
- `f` означает формат числа с плавающей точкой.

Поэтому `fmt.Printf("%.1f\n", 7.0/3.0)` напечатает `2.3`, а `%f` напечатал бы `2.333333`.

Например, `fmt.Printf("%T\n", name)` выведет `string`. Символ `\n` переводит курсор на новую строку. Если глагол не подходит к типу, `fmt` не завершит программу, но выведет диагностическую строку, например `%!d(string=Go)`. Это признак, что формат и переданное значение не совпали.

## Как читать тесты

В `main_test.go` функция `TestAverage` содержит таблицу случаев. Каждый случай описывает входные данные (`total`, `count`) и ожидаемое значение (`want`). Цикл запускает их как отдельные подтесты через `t.Run`.

```go
got := average(test.total, test.count)
if got != test.want {
	t.Fatalf("average(...) = %v, want %v", got, test.want)
}
```

Сначала вычисляется `got`, затем он сравнивается с `want`. При несовпадении `t.Fatalf` завершит подтест и покажет оба значения. Запустите только эти тесты подробным режимом:

```sh
go test -v ./lessons/01-data-types
```

## Типичные ошибки

| Ошибка | Почему неверно | Как исправить |
| --- | --- | --- |
| `7 / 3` в расчёте среднего | Это целочисленное деление, результат `2` | Преобразовать операнды в `float64` до деления |
| Делить на `count`, не проверяя ноль | Для целых чисел программа завершится с panic | Вернуть ошибку или оговорённое значение; в уроке это `0` |
| Использовать `len` для числа русских букв | `len` считает байты | Для кодовых точек использовать `len([]rune(text))` |
| Ожидать округления от `int(3.9)` | Преобразование отбрасывает дробную часть | Явно выбрать правило округления и применить `math` позже |

## Практика

1. Добавьте `Percentage(completed, total int) float64`. При нулевом `total` возвращайте `0`. Напишите табличные тесты.
2. Добавьте `IsASCII(text string) bool`, проверяя байты. Протестируйте ASCII и кириллицу.
3. Напишите `KilometersToMiles(km float64) float64`; задокументируйте коэффициент перевода и проверьте значение с допуском.
4. Объясните в комментарии, почему `len("Привет")` отличается от `len([]rune("Привет"))`.
5. Дополните `main`, чтобы он печатал тип каждого значения через `%T`.

Для `Percentage` проверьте минимум три случая: целый процент, дробный процент и нулевой `total`. Для `IsASCII` ожидайте `true` у `"Go 1.22"` и `false` у `"Привет"`. Не смотрите решения до собственной попытки: тесты должны описывать требуемое поведение.
