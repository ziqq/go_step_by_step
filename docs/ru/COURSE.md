# Go: от первой программы до production

[English version](../COURSE.md)

## Как устроен курс

Каждый урок содержит небольшой запускаемый пример, целевые тесты и задания.
Прочитайте урок, запустите код, измените его и выполните задания до перехода к следующей теме.

Основные команды:

```sh
go fmt ./...
go test ./...
go test -race ./...
go vet ./...
```

В курсе приоритетны стандартная библиотека, простые пакеты, полезные нулевые значения, понятные ошибки и тесты. Интерфейсы появляются только на границе потребителя, когда действительно нужны несколько реализаций. Здесь нет обязательных «слоёв», репозиториев, фабрик и диаграмм Clean Architecture.

## Карта курса

### 1. Основа языка

1. Типы данных, переменные, константы, нулевые значения, преобразования, строки, байты и руны.
2. Операторы, условия, циклы и области видимости.
3. Массивы, срезы, карты и `range`.
4. Функции, несколько возвращаемых значений, `defer` и ошибки.
5. Структуры, методы, указатели и композиция.
6. Интерфейсы, утверждения типов, дженерики и проектирование пакетов.

**Проект:** протестированный консольный трекер расходов с хранением данных в JSON.

### 2. Повседневный Go

7. Файлы, JSON, время, регулярные выражения и флаги командной строки.
8. Табличные тесты, подтесты, тестовые помощники, бенчмарки, фаззинг и покрытие.
9. Модули, зависимости, документация и идиоматичные имена.
10. Context, горутины, каналы, `sync`, отмена операций и race detector.

**Проект:** параллельный консольный анализатор логов.

### 3. Backend-разработка

11. HTTP-серверы на `net/http`, маршрутизация, JSON, валидация и `httptest`.
12. Конфигурация, структурированное логирование, корректное завершение и обработка ошибок на границах API.
13. SQL, PostgreSQL, миграции, транзакции, индексы и тестирование запросов.
14. Аутентификация, авторизация, ограничения частоты запросов и типичные уязвимости веб-приложений.

**Проект:** HTTP API для трекера расходов.

### 4. Production-навыки

15. Docker, конфигурация для разных окружений, health checks и CI.
16. Наблюдаемость: логи, метрики, трассировка и `pprof`.
17. Производительность: бенчмарки, аллокации, профили и нагрузочное тестирование.
18. Надёжность: таймауты, повторы, идемпотентность, очереди и обратное давление.
19. Проектирование систем: API-контракты, кеширование, фоновые задачи и развитие сервиса.

**Итоговый проект:** production-сервис с PostgreSQL, миграциями, API-тестами, наблюдаемостью, Docker и CI.

## Структура проекта по мере роста

Начинайте с одного пакета. Добавляйте каталог только тогда, когда он получает самостоятельную и понятную ответственность. Команды располагаются в `cmd/<name>`, а код, закрытый внутри репозитория, может жить в `internal/<name>`. Не создавайте `pkg` по умолчанию: переносите туда код лишь тогда, когда внешнему проекту действительно нужен стабильный переиспользуемый API.

Материалы курса основаны на официальной документации Go, A Tour of Go, Go by Example и test-first практике Learn Go with Tests. Для изменений языка используйте актуальную документацию Go; Effective Go остаётся полезным для идиом, но появился раньше модулей и дженериков.
